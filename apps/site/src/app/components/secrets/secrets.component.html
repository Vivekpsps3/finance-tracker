Project Secrets

Air-gapped LLM inference with browser ECDH + AES-GCM.

How it works

  1. You type a prompt.
  2. ECDH builds a shared key with the server.
  3. AES-GCM encrypts the prompt in the browser.
  4. A self-hosted LLM unwraps it locally. No logs.
  5. The encrypted reply is decrypted here.
