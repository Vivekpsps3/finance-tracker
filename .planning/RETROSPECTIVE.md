## Milestone: v1.0 — Organization and user-story schema

**Shipped:** 2026-08-30
**Phases:** 2 | **Plans:** 2

### What Was Built
- Planning schema: NW / ACT / CF / PLAN + read-only Overview
- Chrome names the plane (nav, titles, tutorial, badges)
- Leftover period Income/Expenses badges remapped off NW onto ACT+CF

### What Worked
- One epic per existing invariant — no new product surface
- Verify-then-patch: most IA already shipped; one mapping gap was real

### What Was Inefficient
- Checking ROADMAP boxes without CONTEXT/PLAN/VERIFICATION left `/gsd-autonomous` treating both phases as incomplete
- Smart-discuss on already-approved spec added ceremony

### Patterns Established
- Lean stories: ID, want, plane, writes, must not, accept
- Source badges: observed=NW, scheduled=CF, combined=ACT+CF, scenario=PLAN

### Key Lessons
1. GSD completeness is artifacts, not ROADMAP checkboxes.
2. Combined/scenario badges never belong on a net-worth figure.
